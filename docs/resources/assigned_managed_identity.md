# tharsis_assigned_managed_identity (Resource)

Defines and manages an assigned managed identity.

## Example Usage

```terraform
resource "tharsis_assigned_managed_identity" "this" {
  workspace_id        = tharsis_workspace.this.id
  managed_identity_id = tharsis_managed_identity.aws.id
}
```

## Behavior

- A managed identity inherited from a group is not assigned to workspaces automatically. Each workspace that uses it must be assigned the identity.
- Multiple AWS managed identities can be assigned to one workspace. In that case, each AWS provider block must set `profile` to the resource path of the identity it uses.
- Other managed identity types are limited to one per workspace.
