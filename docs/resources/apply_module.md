# tharsis_apply_module (Resource)

Defines and manages tharsis_apply_module resources, which launch runs in other workspaces.

## Example Usage

```terraform
resource "tharsis_apply_module" "this" {
  workspace_id   = tharsis_workspace.this.id
  module_source  = "tharsis.example.com/my-group/my-module/aws"
  module_version = "1.0.0"

  variables = [
    {
      category = "terraform"
      key      = "region"
      value    = "us-east-1"
    }
  ]
}
```

## Behavior

- Creating the resource runs a plan and apply of the module in the target workspace and waits for the run to finish.
- Destroying the resource launches a destroy run, which removes the deployed resources without deleting the workspace.
- `variables` are passed to the run. The variables the run actually used, including inherited ones, are reported in `resolved_variables`.

## Permissions

Only owners and deployers can launch runs.
