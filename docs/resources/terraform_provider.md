# tharsis_terraform_provider (Resource)

Defines and manages a Terraform provider.

## Example Usage

```terraform
resource "tharsis_terraform_provider" "this" {
  name           = "my-provider"
  group_id       = tharsis_group.top_level.id
  private        = true
  repository_url = "https://github.com/my-org/terraform-provider-my-provider"
}
```

## Behavior

- A provider address has the form `hostname/namespace/type`, where the namespace is the path of the group that contains the provider.
- The name is the provider type. It may contain digits, lowercase letters, hyphens, and underscores, and cannot start or end with a hyphen or underscore. It must be unique within the group.
- Provider versions must follow Semantic Versioning 2.0 and are not managed by this resource.
- Uploading provider versions requires a GPG key to have been added to the group. See `tharsis_gpg_key`.

## Schema

### Required

- `name` (String) The name of the Terraform provider.

### Optional

- `group_id` (String) The ID or TRN of the parent group.
- `group_path` (String, Deprecated) The path of the group where this Terraform provider resides.
- `private` (Boolean) Whether this Terraform provider is hidden from other top-level groups.
- `repository_url` (String) The repository URL where this Terraform provider can be found.

### Read-Only

- `id` (String) String identifier of the Terraform provider.
- `last_updated` (String) Timestamp when this Terraform provider was most recently updated by Terraform.
- `registry_namespace` (String, Deprecated) The top-level group where this Terraform provider resides.
- `resource_path` (String, Deprecated) String identifier of this Terraform provider.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# A Terraform provider can be imported by its path, which is the group path plus
# the provider name.
terraform import tharsis_terraform_provider.this my-group/my-provider

# The provider's TRN also works.
terraform import tharsis_terraform_provider.this trn:terraform_provider:my-group/my-provider

# So does its ID, shown by the "id" attribute or in the Tharsis UI.
terraform import tharsis_terraform_provider.this <terraform-provider-id>
```
