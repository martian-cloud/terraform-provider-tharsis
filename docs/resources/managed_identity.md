# tharsis_managed_identity (Resource)

Defines and manages a managed identity.

## Example Usage

```terraform
resource "tharsis_managed_identity" "aws" {
  name        = "my-aws-identity"
  description = "Federated AWS identity."
  type        = "aws_federated"
  group_id    = tharsis_group.top_level.id
  aws_role    = "arn:aws:iam::123456789012:role/my-role"
}

# Azure and Tharsis identities use their own attributes instead of aws_role:
#
# resource "tharsis_managed_identity" "azure" {
#   name            = "my-azure-identity"
#   type            = "azure_federated"
#   group_id        = tharsis_group.top_level.id
#   azure_client_id = "<client_id>"
#   azure_tenant_id = "<tenant_id>"
# }
#
# resource "tharsis_managed_identity" "tharsis" {
#   name                         = "my-tharsis-identity"
#   type                         = "tharsis_federated"
#   group_id                     = tharsis_group.top_level.id
#   tharsis_service_account_path = "my-group/my-service-account"
# }
```

## Behavior

- A managed identity assumes cloud provider credentials through OIDC federation, so no credentials are stored.
- The `type` determines which other attributes are required:
  - `aws_federated` requires `aws_role`.
  - `azure_federated` requires `azure_client_id` and `azure_tenant_id`.
  - `tharsis_federated` requires `tharsis_service_account_path`.
- A managed identity is created in a group and inherited by its child groups. Inheritance does not assign it: each workspace must be assigned the identity, for example with `tharsis_assigned_managed_identity`.
- By default, anyone with deployer access to the identity can assume it. Use `tharsis_managed_identity_access_rule` to restrict this.
- A name cannot be changed after creation. Only the description and provider configuration can be edited.

## Permissions

Only the owner role can create, update, or delete managed identities.

## Import

Import is supported using the following syntax:

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
# A managed identity can be imported by its TRN, which is "trn:managed_identity:"
# followed by the group path and the identity name.
import {
  to = tharsis_managed_identity.aws
  id = "trn:managed_identity:my-group/my-aws-identity"
}

# The identity's ID also works as the id, shown by the "id" attribute or in the
# Tharsis UI.
```
