# tharsis_vcs_provider (Resource)

Defines and manages a VCS provider.

## Example Usage

```terraform
resource "tharsis_vcs_provider" "this" {
  name                 = "my-vcs-provider"
  description          = "GitLab VCS provider."
  type                 = "gitlab"
  group_id             = tharsis_group.top_level.id
  url                  = "https://gitlab.com"
  oauth_client_id      = "<oauth_client_id>"
  oauth_client_secret  = "<oauth_client_secret>"
  auto_create_webhooks = true
}
```

## Behavior

- The supported types are `github` and `gitlab`.
- A VCS provider is created within a group and inherited by its child groups.
- `url` is optional. If omitted, the public API URL for the provider type is used.
- `url` and `auto_create_webhooks` cannot be changed after creation.
- If `auto_create_webhooks` is false, webhooks must be configured manually in the repository.

## OAuth

The OAuth client ID and secret are never displayed by Tharsis. After the provider is created, complete the OAuth flow using the `oauth_authorization_url` attribute.

## Deletion

Deleting a VCS provider is irreversible and severs the connection to the OAuth application.
