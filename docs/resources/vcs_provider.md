# tharsis_vcs_provider (Resource)

Defines and manages a VCS provider.

## Example Usage

```terraform
resource "tharsis_vcs_provider" "this" {
  name                 = "my-vcs-provider"
  description          = "GitLab VCS provider."
  type                 = "gitlab"
  group_id             = tharsis_group.top_level.id
  url                  = "https://gitlab.com"
  oauth_client_id      = "<oauth_client_id>"
  oauth_client_secret  = "<oauth_client_secret>"
  auto_create_webhooks = true
}
```

## Behavior

- The supported types are `github` and `gitlab`.
- A VCS provider is created within a group and inherited by its child groups.
- `url` is optional. If omitted, the public API URL for the provider type is used.
- `url` and `auto_create_webhooks` cannot be changed after creation.
- If `auto_create_webhooks` is false, webhooks must be configured manually in the repository.

## OAuth

The OAuth client ID and secret are never displayed by Tharsis. After the provider is created, complete the OAuth flow using the `oauth_authorization_url` attribute.

## Deletion

Deleting a VCS provider is irreversible and severs the connection to the OAuth application.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# A VCS provider can be imported by its path, which is the group path plus the
# provider name.
terraform import tharsis_vcs_provider.this my-group/my-vcs-provider

# The provider's TRN also works.
terraform import tharsis_vcs_provider.this trn:vcs_provider:my-group/my-vcs-provider

# So does its ID, shown by the "id" attribute or in the Tharsis UI.
terraform import tharsis_vcs_provider.this <vcs-provider-id>

# Note: oauth_client_id and oauth_client_secret are write-only and cannot be
# read back from Tharsis, and oauth_authorization_url is only returned when the
# provider is first created. After importing, set the two OAuth credentials in
# your configuration to match the values the provider was created with, or the
# next apply will update them.
```
