# tharsis_workspace_vcs_provider_link (Resource)

Defines and manages a workspace VCS provider link.

## Example Usage

```terraform
resource "tharsis_workspace_vcs_provider_link" "this" {
  workspace_id          = tharsis_workspace.this.id
  vcs_provider_id       = tharsis_vcs_provider.this.id
  repository_path       = "my-org/my-project"
  branch                = "main"
  module_directory      = "terraform"
  glob_patterns         = ["terraform/**"]
  auto_speculative_plan = true
  webhook_disabled      = false
}
```

## Behavior

- A workspace can be linked to only one VCS provider, although a VCS provider can be linked to many workspaces.
- `repository_path` is the path portion of the repository URL (for example `my-org/my-repo`), not the full URL. It cannot be changed after creation.
- Linking a different VCS provider replaces the existing link.
- If unset, `branch` defaults to the repository's default branch and `module_directory` defaults to the repository's base directory.

## Triggering runs

- A run is triggered automatically by a push to the tracked branch, or by a tag matching `tag_regex`. If `tag_regex` is unset, tagged commits are ignored.
- Automatic runs are limited to commits that change files matching any of the `glob_patterns`.
- With `auto_speculative_plan`, speculative plans are created for pull or merge requests that target the branch.
- When `webhook_disabled` is true, all webhook events are ignored. Runs can still be started manually.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# A link has no human-readable name, so import it by its ID, shown by the "id"
# attribute or in the Tharsis UI.
terraform import tharsis_workspace_vcs_provider_link.this <link-id>

# A TRN works too, but its last segment is the same link ID, so it offers no
# advantage over using the ID on its own.
terraform import tharsis_workspace_vcs_provider_link.this trn:workspace_vcs_provider_link:my-group/my-workspace/<link-id>
```
