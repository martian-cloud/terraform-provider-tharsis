# tharsis_workspace_role_binding (Resource)

Defines and manages a workspace role binding.

## Example Usage

```terraform
resource "tharsis_workspace_role_binding" "wrb" {
  workspace_id = tharsis_workspace.this.id
  role_name    = "deployer"
}
```

## Behavior

- A workspace role binding confers a role on a workspace. The role's permissions become available to the workspace's job caller at the workspace's direct parent group and its descendants.
- A job is read-only by default. Create a workspace role binding to allow the workspace's jobs to create or change resources, such as with this provider running inside a Tharsis job.
- The role is limited to what the role itself permits. Choose the least privileged role that covers what the job needs to do.
- `role_name` can be changed in place. Changing `workspace_id` replaces the role binding.

## Schema

### Required

- `workspace_id` (String) The ID or TRN of the workspace this role binding applies to.

## Import

Import is supported using the following syntax:

In Terraform v1.5.0 and later, the [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the `id` attribute, for example:

```terraform
# A role binding is identified by the workspace it applies to, so it is
# imported using the workspace's TRN.
import {
  to = tharsis_workspace_role_binding.wrb
  id = "trn:workspace:my-group/my-workspace"
}

# The workspace's ID also works as the id, shown by the "id" attribute of a
# tharsis_workspace resource or in the Tharsis UI.
```
